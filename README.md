#  Proyecto de Verificación Facial para Repartidores

Este proyecto implementa un **sistema de verificación facial en tiempo real** utilizando técnicas de **Visión por Computadora**, con el objetivo de validar la identidad de repartidores mediante **reconocimiento facial**, mejorando la seguridad y confiabilidad en los procesos de autenticación.

Proyecto desarrollado como parte del curso **Percepción y Visión por Computadora** – **Universidad Nacional de Trujillo**.

---

##  Características principales

-  Captura de video en tiempo real desde la cámara  
-  Detección y verificación facial  
-  Comparación de rostros con un modelo previamente registrado  
-  Indicación visual del estado de verificación  
-  Estructura modular para fácil mantenimiento y escalabilidad  

---

##  Tecnologías utilizadas

- **Python 3**
- **OpenCV**
- **NumPy**
- **Librerías de reconocimiento facial**
- **Git & GitHub**
